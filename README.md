# Personal Profile Webpage

Open `index.html` locally to preview the website.

Files:
- index.html
- style.css
- profile.jpg

Before submission, replace the placeholder name, college/school details, email and social links.

For GitHub Pages:
1. Create a public repository.
2. Upload all three website files and the image.
3. Settings → Pages → Deploy from a branch → main → /(root) → Save.
4. Open the generated GitHub Pages URL.
